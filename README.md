# Java DSA

My journey learning Data Structures and Algorithms using Java.

---

## 📖 About
This repository contains my personal implementations, concepts, and problem solutions for Data Structures and Algorithms (DSA) using **Java**. 
It tracks my step-by-step progress from foundational concepts like basic syntax and control flow to advanced topics such as Dynamic Programming, Graphs, and Tries.

---

## 🗺️ Learning Roadmap
```text
Java Basics ──► Searching & Sorting ──► Recursion & Backtracking ──► Data Structures (LL, Trees, Heaps) ──► Advanced Algorithms (DP, Graphs)
```

## 💻 How to Run Java Programs
To compile and run any Java program from the command line:

```bash
# Navigate to topic directory
cd 05-arrays

# Compile the Java file
javac ArrayBasics.java

# Run the compiled bytecode class
java ArrayBasics
```
