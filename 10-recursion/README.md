# Recursion & Backtracking

## 📌 Overview
Solving problems by breaking them into smaller instances of the same problem using function call stacks.

---

## 💡 Important Concepts
- Base Case & Recursive Case
- Call Stack Visualization & Stack Overflow
- Tail Recursion
- Subsequences & Subsets generation
- Backtracking (Exploring all paths & resetting state)
