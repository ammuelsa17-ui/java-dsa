# Tries (Prefix Trees)

## 📌 Overview
Tree-like data structure used for efficient retrieval of keys in a dataset of strings.

---

## 💡 Important Concepts
- Trie Node Structure (Children array/map, isEnd flag)
- Insertion & Search Operations
- Prefix Matching (`startsWith`)
- Memory Management in Tries
- Bitwise Trie (XOR Maximum Problems)
