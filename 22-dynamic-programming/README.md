# Dynamic Programming

## 📌 Overview
Optimization technique over overlapping subproblems with optimal substructure.

---

## 💡 Important Concepts
- Top-Down Approach (Memoization)
- Bottom-Up Approach (Tabulation)
- State Definition & Transition Equations
- 1D DP, 2D DP, Grid DP
- Knapsack Problems (0/1 & Unbounded)
- Longest Common Subsequence (LCS)
